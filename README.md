# Precious Metals Market Analyzer

An interactive Python and machine-learning application for exploring historical gold and silver market behaviour.

## Project Goal

This project uses precious-metals market data to develop practical skills in:

- Python programming
- Data cleaning and analysis
- Feature engineering
- Machine learning
- Interactive web application development
- Model evaluation and explainability

## Planned Features

- Historical gold and silver price exploration
- Return and volatility analysis
- Gold-silver ratio analysis
- K-Means market-condition clustering
- Isolation Forest anomaly detection
- Explainable machine-learning results
- Interactive Streamlit dashboard

## Current Status

The initial Streamlit application and Python environment have been created.

## Technology Stack

- Python
- pandas
- Streamlit
- Plotly
- scikit-learn
- pytest
- Git and GitHub

## Disclaimer

This project is intended for educational and analytical purposes. It does not provide financial advice, trading recommendations, or guaranteed market predictions.
